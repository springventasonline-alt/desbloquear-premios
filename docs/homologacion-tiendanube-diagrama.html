1. Instalación y autenticación OAuth

El comerciante instala la app desde el marketplace o el enlace de instalación. Se valida el state anti-CSRF, se intercambia el código por access_token, se persiste la tienda y se activa el script asociado. 

sequenceDiagram
    autonumber
    actor Merchant as Comerciante
    participant TN as Tiendanube (OAuth)
    participant App as App Backend (Railway)
    participant DB as PostgreSQL
    participant API as API Tiendanube

    Merchant->>TN: Instalar app 33285 / autorizar permisos
    TN->>App: GET /auth/install (opcional, flujo propio)
    App->>DB: INSERT oauth_states (state CSRF)
    App->>TN: Redirect authorize?state=...
    TN->>Merchant: Pantalla de consentimiento OAuth
    Merchant->>TN: Acepta permisos
    TN->>App: GET /auth/callback?code=...&state=...
    App->>DB: consumeOAuthState(state) — validación CSRF
    App->>TN: POST /apps/authorize/token (code + client_secret)
    TN-->>App: access_token, scope, user_id (store_id)
    App->>API: GET /v1/{store_id}/store (Bearer token)
    API-->>App: nombre, URL tienda
    App->>DB: upsert stores (token, metadatos)
    App->>App: activateStoreScript(store)
    alt Script auto-instalado (Partner Portal)
        App->>DB: script_installed = true
        Note over TN,App: Tiendanube ya inyecta el script al instalar la app
    else Script manual (API)
        App->>API: POST /v1/{store_id}/scripts/{script_id}
        API-->>App: script asociado (active/testing)
    end
    App->>App: Sesión admin (storeId)
    App->>Merchant: Redirect /admin (panel configuración)

2. Inyección del widget en la tienda (script)

Con «Auto instalado» activo en el Partner Portal, Tiendanube sirve el JS desde su CDN en el storefront (evento onfirstinteraction). El widget no modifica archivos del tema; se monta en el DOM del carrito usando el objeto global LS.

    Buyer->>Store: Navega tienda / abre carrito
    Store->>Store: Carga HTML carrito (tema + slots nubesdk)

    Store->>CDN: Solicita script (handle desbloquear-premios-barra)

    Store->>Widget: Ejecuta script (onfirstinteraction)
    Widget->>Widget: Lee LS.store.id (ID tienda)
    Widget->>Widget: Observa LS.cart / DOM panel carrito
    Widget->>Store: Inyecta barra de progreso en contenedor carrito
    Note over Widget,Store: Modo dev alternativo: /widget/rewards-bar.js desde Railway

3. Carrito consulta configuración de premios al backend

Tras montar la UI, el widget obtiene umbrales, textos y colores desde la API pública. Solo responde si la tienda está activa y la configuración está habilitada. 

sequenceDiagram
    autonumber
    participant Widget as Widget (storefront)
    participant API as App Backend
    participant DB as PostgreSQL

    Widget->>Widget: resolveStoreId() → LS.store.id
    Widget->>API: GET /api/widget/{storeId}
    API->>DB: findStore + reward_config + reward_levels
    alt Tienda inexistente o config deshabilitada
        API-->>Widget: 404 — no muestra barra
    else Config activa
        API-->>Widget: JSON (colores, textos, niveles, umbrales)
        Widget->>Widget: Calcula subtotal LS.cart.subtotal / 100
        Widget->>Widget: Renderiza progreso y premios desbloqueados
        loop Actualización carrito (poll / DOM)
            Widget->>Widget: Detecta cambio LS.cart.subtotal
            Widget->>Widget: Recalcula progreso vs umbrales
        end
    end
    Note over API: Cache-Control: public, max-age=60
    Note over Merchant: Comerciante edita premios en /admin → persiste en DB

4. Desinstalación de la app

Al desinstalar desde el admin de Tiendanube se envían webhooks GDPR. La app marca la tienda como desinstalada; Tiendanube deja de inyectar el script automáticamente. 

sequenceDiagram
    autonumber
    actor Merchant as Comerciante
    participant TN as Tiendanube
    participant App as App Backend
    participant DB as PostgreSQL
    participant Store as Storefront

    Merchant->>TN: Desinstalar app desde panel Apps
    TN->>TN: Revoca tokens OAuth de la app
    TN->>TN: Deja de cargar script auto-instalado (7124)
    TN->>App: POST /webhooks/app/uninstalled { store_id }
    App->>DB: UPDATE stores SET uninstalled_at = NOW()
    TN->>App: POST /webhooks/store/redact (GDPR, opcional)
    App->>DB: markStoreUninstalled (idempotente)
    App-->>TN: 200 { received: true }
    Store-->>Buyer: Carrito sin barra de premios
    Note over App: Scripts manuales: DELETE /v1/{store}/scripts vía API si aplica
    Note over DB: Datos conservados según política; tienda excluida de APIs activas
